# 生成质量改进的需求与决策

日期：2026-10-15，Asia/Shanghai。用户在本会话明确要求实施《ThreeJSON / ThreeBox 生成质量与视觉表现改进计划》，无需分阶段人工验收。此记录是需求批准，不是最终画面人工验收。

用户反馈模型粗糙、灯光昏暗、视频运镜欠佳。批准的方案先修复可证实的几何、参数、预览/导出差异，再建立质量档位、专业配方、真实画面反馈和受控资产。四档默认快速；预算上限不等于完成。外部模型默认允许，但服务端与个人开关必须同时生效；不能以关闭新获取破坏历史项目、纹理、本地导入。

保留友好 JSON、普通源文档、可编辑算子、明确的精确网格。没有为审美重造 JSON，也没有自动烘焙模型。桌面编辑器、完整视频剪辑软件重做、电影级路径追踪、CAD 制造约束均不在本期。

授权范围是本地实现和验证，不包括发布 npm、推送、部署、线上数据库修改、调用付费供应商。历史方案只用于解释奇怪设计；本轮实现依据当前代码与已批准方案。
