# 需求与方案

## 范围与边界

1. 在 Core 通用输入适配处支持 group 的 children 别名（仅 subScene 未定义或为空时）；有冲突不静默拼接；native 与几何内部 children 不参与。保持源文档不变，规范输出仍为 subScene。
2. 对参数曲面的 func 只兼容可证明安全的算术箭头子集（两个参数、顺序 const 数值表达式、返回三维数组），转为现有 geometry.expressions。拒绝任意调用、属性访问、赋值、循环等；不使用 eval / Function，不硬编码样本公式。规范 expressions 优先。
3. 提取可复用媒体预检查：检查格式、范围、原有音轨与各镜头实际加载/渲染，且在宿主合成旁白之前调用。按镜头显示检查进度；不是最终画面审美验收。失败和取消不开始配音或编码。
4. 宿主优先写站点私有临时文件，完整封装后才提供保存。支持选择保存路径的浏览器显示“保存视频”，用户手势内再打开文件选择器；没有该能力则下载完成的文件。保存失败/取消可重试，不重复配音与渲染。临时存储不可用时保留已有 Blob 路径；不在用户目标路径预建空文件。
5. Core 仅处理通用描述符，media-kit 负责可执行性与编码，host-kit 负责保存 UX/临时存储；不增加反向依赖，不修改文档 production 完成状态或自动改变音乐循环语义。

## 验证与风险

- 单测：层级递归、原文不可变、双数组冲突/native 隔离；安全表达式白名单、拒绝有副作用代码、规范表达式优先；预检查早于音频合成和文件目标调用；取消、编码/写入失败、保存重试。
- 浏览器：原始 8 镜头检查；循环音轨后导出原始 150 秒文档（低分辨率回归，不声称全规格性能验证）；真实 MP4/WebM 解析、非零大小及完整时长；晚镜头人为错误在旁白及保存前失败；临时文件清理；现有旁白导出测试。
- 私有存储配额或写入失败明确报错，不静默降为无音轨/短视频；不得删除用户已有文件。已完成临时结果在窗口内保存重试，关闭窗口时释放。
- 不改变未经支持的复杂 JS 语义：无法转换时提前报告，不能执行它，也不能丢弃镜头继续导出。
- 文档同步中英文媒体与场景契约。回滚按模块撤销，不重写用户 JSON。
