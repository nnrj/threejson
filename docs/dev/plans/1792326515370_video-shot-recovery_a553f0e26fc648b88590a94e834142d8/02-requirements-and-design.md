# 范围与设计

1. media-kit 从现有 SceneOperation 注册表提供按需 `media.shot.discover`：无筛选返回轻量目录，
   指定命令返回真实参数契约，不复制另一套命令定义，也不把全部建模 schema 塞进每轮提示词。
2. query/edit 的嵌套命令提供明确结构及语义验证；未知命令、读写入口错误、参数错误、
   无运行时能力分别返回 code、镜头/命令定位与可执行的发现或修正指引。绝不自动把查询升级为写入。
3. 通用 Agent 在同一失败调用重复时，仅在服务提供具体 recovery 的情况下提示一次明确纠错，
   不重新执行该失败调用；再重复则仍停止。成功的重复写入、预算、取消保护不变。
   文档已被修复后允许在新 revision 重试此前失败的操作，不能把失败当成已执行。
4. 视频 Agent 首轮包含本地读取的存档摘要、验证结果和历史失败，补齐查询/编辑/发现示例。
   共享宿主持久化最新错误代码，并在操作契约错误时给出用户可理解的提示。
5. 视频编辑器的单镜头作用域允许无副作用的契约发现，但不能借此改其他镜头。

## 验收

- 用服务与确定性假供应商复现未知只读命令误报和重复失败；修复后可发现契约并继续正确编辑。
- query 对混合读写批次保持全拒绝且 revision、撤销栈不变；编辑失败原子回滚。
- 参数缺失返回确切参数名与 schema；运行时截图指向 media.captureFrames，不伪造成功。
- JSONL 和 native 两种协议恢复正确，无孤立 tool 消息；取消和显式预算仍立即生效。
- 用既有 150 秒/8 镜头夹具恢复，保留镜头、音轨、时间；成功不保留陈旧错误。
- 共享宿主同步/架构测试以及媒体会话、视频 Agent、视频编辑器相关回归。
- 结果仅为本地契约与编排验证；未获授权不做线上真实模型或付费测试。
